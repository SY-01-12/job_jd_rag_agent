# AI Agent 应用开发实习岗位知识文档


## 1. 岗位定位

AI Agent 应用开发实习生通常不是大模型训练岗，也不是纯算法研究岗，而是面向大模型应用落地的工程实习岗位。岗位目标是把大模型能力接入实际业务场景，例如知识库问答、工作流助手、岗位分析工具、客服助手、文档问答系统、自动化数据处理工具等。

这类岗位通常要求候选人掌握 Python、FastAPI、大模型 API 调用、LangChain、RAG、向量数据库、Prompt 编写、工具调用和基础工程能力。有些公司还会要求 Dify、Coze、Docker、Linux、Git 等工具使用经验。

在实际项目中，不能只背概念，而要能说明它在系统流程中的位置。一个可讲清楚的回答通常包括三点：它是什么、解决什么问题、如何在项目中落地。对于 AI Agent 应用开发实习，面试官更关注候选人是否理解工具调用、RAG 检索、向量库、Prompt 约束和接口化服务之间的关系，而不是只会说某个框架名称。


## 2. 常见岗位职责

AI Agent 应用开发实习生的职责通常包括：参与大模型应用原型开发；使用 LangChain、Dify 或 Coze 搭建 Agent；构建知识库问答流程；完成文档解析、文本切块和向量检索；封装工具调用；对接外部 API；编写 Prompt；调试 RAG 效果；整理技术文档和测试结果。

如果岗位偏工程，还可能要求使用 FastAPI 封装接口，提供 /chat、/rag/chat、/agent/chat 等服务。如果岗位偏平台应用，可能要求会 Dify Workflow、Coze 插件和知识库配置。如果岗位偏检索增强，可能更看重 BM25、BGE、FAISS、Chroma 和 Reranker。

在实际项目中，不能只背概念，而要能说明它在系统流程中的位置。一个可讲清楚的回答通常包括三点：它是什么、解决什么问题、如何在项目中落地。对于 AI Agent 应用开发实习，面试官更关注候选人是否理解工具调用、RAG 检索、向量库、Prompt 约束和接口化服务之间的关系，而不是只会说某个框架名称。


## 3. 必备技术栈

Python 是大模型应用开发最常用语言，用于数据处理、接口开发、工具函数、LangChain 编排和脚本运行。FastAPI 用于把大模型和 Agent 能力封装成后端接口。LangChain 用于模型调用、Prompt 管理、Tool 定义、Agent 调度、Retriever 检索和 RAG 链构建。RAG 用于让大模型基于本地知识库回答问题，减少幻觉并支持引用来源。

向量数据库是 RAG 的重要组成部分，Chroma 和 FAISS 是常见选择。Chroma 更适合初学者和简历项目，FAISS 更偏高性能本地向量检索。工具调用能力也很关键，Agent 必须能调用 calculator、read_file、extract_keywords 和 rag_search。

## 4. 加分技能

Git 是基础版本管理工具，实习开发中基本必备。Linux 常用命令用于服务器运行、查看日志、管理文件和排查进程。Docker 用于部署 Dify、数据库或服务。Postman 和 Swagger 用于接口调试。Conda 用于 Python 环境管理。

## 5. 岗位 JD 技能抽取

岗位 JD 分析 Agent 的一个核心功能是从岗位描述中提取技能关键词。常见关键词包括：Python、FastAPI、LangChain、LangGraph、LlamaIndex、Dify、Coze、RAG、BM25、BGE、FAISS、Chroma、Milvus、Reranker、Embedding、Prompt、Tool Calling、Function Calling、ReAct、OpenAI API、通义千问、DeepSeek API、Docker、Linux、Git、Postman、Swagger、MySQL、Redis。

关键词提取可以先用规则实现。规则版本不依赖大模型，稳定、可控，适合作为工具函数。后续可以升级为大模型抽取，让模型返回结构化 JSON，包括核心技能、岗位职责、加分项和学习建议。

## 6. 岗位分析工作流

岗位分析工作流可以拆成多个步骤。第一步读取或输入岗位 JD。第二步提取技术关键词。第三步根据知识库解释这些技术的作用。第四步判断岗位类型，例如 Agent 应用开发、RAG 开发、后端开发或算法研究。第五步根据用户当前基础生成学习路线。第六步给出简历优化建议。

这种流程适合用 Agent Runner 或 Dify Workflow 实现。代码版更能体现工程能力，平台版更能体现快速应用搭建能力。
